# Remonda Ropil — Portfolio

Premium personal portfolio built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

```
public/assets/        images
src/
  data/portfolio.js   all content (single source of truth)
  hooks/              useTheme, useReveal
  components/         Navbar, Hero, About, Skills,
                      Projects, ProjectModal, Experience,
                      Contact, Footer
```

Dark/light theme, responsive layout, accessible markup,
project detail modals and scroll-reveal animations included.
